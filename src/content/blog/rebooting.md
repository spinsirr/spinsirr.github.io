This is a reboot. The old version of this site was a student blog full of JavaScript
tutorials and LeetCode write-ups. They were useful when I wrote them, but the site stopped
reflecting what I actually work on.

These days I'm a cofounder and engineer at CoreSpeed. I work on connectors, memory,
gateways, billing, and product systems for cloud agents. I rebuilt this place to match:
a clean home for my projects, the stack I use, and notes grounded in the work.

It's built with [Astro](https://astro.build/) and shipped as a static site. Expect posts
on agent infrastructure, memory evaluation, and projects as they ship.
